## Entry

**unhinged**

The whole internet in one beat: not addictive, not infinite, not crazy — unhinged. Every feed, every thread, every comment section slightly off its rails at once.

## How it works

`main.py` (stdlib only) writes the single word to `/output/entry.txt` (or `MAKEFUN_OUTPUT_DIR`), validates it against the gate (1–30 characters, single word, not whitespace-only), then reads it back to prove the file on disk is byte-exact.
